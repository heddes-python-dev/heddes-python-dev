### 🛠️ Admin & System Tool Suite
* **[local-traffic-monitor](https://github.com/heddes-python-dev/local_traffic_monitor)**: Modularer Netzwerkmonitor zur Live-Analyse von Bandbreite und TCP/IP-Verbindungen. Inklusive Offline-GeoIP-Auswertung (MaxMind GeoLite2) und Tkinter-GUI.
* **[system-monitor](https://github.com/heddes-python-dev/system_monitor)**: Modularer Systemmonitor zur Überwachung von CPU, RAM, Festplatten und Temperatur mit Benachrichtigungen und Log-Rotation.
* **[netzwerk-monitor](https://github.com/heddes-python-dev/netzwerk_monitor)**: Tool zur Überwachung von Netzwerkverbindungen, Host-Erreichbarkeit und Latenzen mit grafischer Benutzeroberfläche.
* **[log-watcher](https://github.com/heddes-python-dev/log_watcher)**: Zentrales GUI-Überwachungstool (Tail-Ansicht), das Log-Dateien über Background-Threads einspeist, filtert und optisch aufbereitet.
